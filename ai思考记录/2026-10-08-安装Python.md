# 安装 Python 环境

- 日期：2026-10-08
- 等级：L1 语法
- 来源：对话（在这台电脑上安装 Python，方便开始写代码）

## 今天学到的

这台电脑一开始不能写 Python。命令行里能看到 `python` 和 `python3`，但它们指向 `C:\Users\ha\AppData\Local\Microsoft\WindowsApps\`，是 Windows 商店的快捷方式，不是真正的解释器。运行后退出码是 `9009`，也没有版本号。`py` 启动器不存在。

安装时先用 `winget` 找官方包，选定 Python 3.13.15。从 python.org 下载安装包时文件停在 0 字节，这次下载被停掉。

随后从华为镜像下载安装包 `python-3.13.15-amd64.exe`（约 28 MB）。下载时证书吊销检查连不上，使用了 `curl` 的 `--ssl-no-revoke` 才下完。

安装范围是当前用户，安装程序退出码是 `0`。装好后版本是 Python 3.13.15，`pip` 是 26.2.1。

## 关键概念

- WindowsApps 里的 `python.exe`：商店占位程序。能在路径里被找到，但不能运行代码。
- 它解决什么问题：区分「命令存在」和「解释器真的能用」。要看版本号和退出码。
- 用户级安装：只给当前 Windows 用户用，不需要装到所有用户。
- `Path`：系统用来寻找 `python` 命令的目录列表。安装时勾了把 Python 目录放到用户 `Path` 前面。
- `pip`：给这个 Python 安装第三方库的工具。本次已经随 Python 装上。

安装后的位置：

- 解释器：`C:\Users\ha\AppData\Local\Programs\Python\Python313\python.exe`
- 写入用户 `Path` 的目录：
  - `C:\Users\ha\AppData\Local\Programs\Python\Python313\Scripts\`
  - `C:\Users\ha\AppData\Local\Programs\Python\Python313\`
  - `C:\Users\ha\AppData\Local\Programs\Python\Launcher\`

实际使用的安装参数：

```text
/quiet InstallAllUsers=0 PrependPath=1 Include_pip=1 Include_test=0 Include_launcher=1
```

- `InstallAllUsers=0`：只装给当前用户。
- `PrependPath=1`：把 Python 目录加到用户 `Path` 的前面。
- `Include_pip=1`：同时安装 `pip`。
- `Include_test=0`：不安装测试套件。
- `Include_launcher=1`：安装 `py` 启动器。

## 最小例子

新开一个终端后，用下面两行确认环境。已经打开的旧终端还记着安装前的 `Path`，里面的 `python` 仍可能是商店快捷方式。

```powershell
python --version
python -m pip --version
```

能分别看到 `Python 3.13.15` 和 `pip 26.2.1`，就可以开始写。

```python
# 用刚装好的解释器跑一行，确认能执行代码
print("环境可用")
```
