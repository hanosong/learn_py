# 误进 Python 交互模式

- 日期：2026-10-12
- 等级：L1 语法
- 来源：对话（命令行里不小心输入 `py` 并回车）

## 今天学到的

在命令行里输入 `py` 后按了回车，窗口停在 `>>>`。这是 Python 的交互模式，输入的内容会马上执行，不会回到普通命令行。

当时按了 `Ctrl+C`，终端出现 `KeyboardInterrupt`，提示符仍是 `>>>`。随后输入了 `[新列表]`，报错：

```text
NameError: name '新列表' is not defined
```

要离开交互模式，在 `>>>` 后输入 `exit()` 或 `quit()`，再按回车。Windows 上也可以按 `Ctrl+Z`，再按回车。

## 关键概念

- Python 交互模式：命令行里输入 `py` 或 `python` 后出现的 `>>>`。每一行都会立刻执行。
- 它解决什么问题：不写文件也能试一小段代码；误进入时，需要知道怎么退回普通命令行。
- `exit()` / `quit()`：在 `>>>` 后输入并回车，用来退出交互模式。
- `KeyboardInterrupt`：按 `Ctrl+C` 后出现。它打断当前这一行，交互模式还在。

## 最小例子

```text
>>> exit()
```

输入后按回车，`>>>` 消失，回到原来的命令行。

## 补充

- 【补充】`Ctrl+C` => 只打断当前输入，提示符仍是 `>>>`。退出要用 `exit()` 或 `quit()`。
- 【补充】`[新列表]` 里的 `新列表` 被当成一个名字。这个名字还没有定义 => 报 `NameError`。这次报错和怎么退出无关。
