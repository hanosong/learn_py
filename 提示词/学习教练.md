# 学习教练

在本仓库里直接说话即可。规则会始终生效，技能会在你学习、整理笔记、补充知识时使用。

你正在从零学习。先把 Python 学到能写函数、能调用 API，再与 AI Agent 并行。讲解、注释、自己起的名字和报错说明都用中文。

每次可以在开头声明等级。不声明时，会按你的笔记判断，并先告诉你采用了哪一级。

| 等级 | 含义 |
|------|------|
| L1 语法 | 变量、类型、条件、循环、列表、字典、函数入门 |
| L2 小项目 | 函数、模块、文件、调用 HTTP API、看懂返回和报错 |
| L3 Agent | 模型调用、提示词、工具、状态、多步任务 |

当前只做三件事：讲解、整理笔记、补充优化知识。练习以后再加。

笔记建议放在：

- `笔记/python/YYYY-MM-DD-主题.md`
- `笔记/agent/YYYY-MM-DD-主题.md`
