# 笔记格式

整理或优化笔记时使用此结构。没有的信息写「未记录」，不要编造视频标题、讲师原话或用户没写过的例子。

```markdown
# 标题

- 日期：YYYY-MM-DD
- 等级：L1 语法 | L2 小项目 | L3 Agent
- 来源：视频 / 自学 / 对话（知道具体名称就写上）

## 今天学到的

用用户自己的意思写成完整句子。保留用户写过的 `=>`（原因 `=>` 结果，名字 `=>` 含义，上一步 `=>` 下一步）。图里有、用户没写过的句子，句首标 `【来自截图】`。

## 关键概念

- 概念名：一句话定义
- 它解决什么问题：

## 最小例子

\`\`\`python
# 中文注释说明这一行在做什么
\`\`\`

没有代码就写「本篇没有代码」。

## 补充

- 【补充】当前等级下缺少的知识点。没有则写「无」。

## 修正

- 【修正】原来的说法 → 更准确的说法。没有则写「无」。

## 前后连接

- 已经学过、本篇用到的：
- 下一步只学一个相关点：
- 要等会写函数并调用 API 之后再学的：没有则写「无」。

## 截图

保留原图链接。没有截图就写「无」。
```
