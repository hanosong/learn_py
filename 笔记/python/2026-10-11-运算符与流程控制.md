## 今天学到的

算术运算符里，`//` 是整除，笔记记的是向下取整。`%` 是求余数。`**` 是幂运算，`2 ** 3` 是 2 的 3 次方。

赋值运算符在算出新值的同时写回左边的名字。【来自截图】

| 运算符 | 说明 | 例子 |
| --- | --- | --- |
| `=` | 赋值 | `a = 1` |
| `+=` | 加法赋值 | `a += 2`，等同于 `a = a + 2` |
| `-=` | 减法赋值 | `a -= 2`，等同于 `a = a - 2` |
| `*=` | 乘法赋值 | `a *= 2`，等同于 `a = a * 2` |
| `/=` | 除法赋值 | `a /= 2`，等同于 `a = a / 2` |
| `//=` | 整除赋值 | `a //= 2`，等同于 `a = a // 2` |
| `%=` | 求余赋值 | `a %= 2`，等同于 `a = a % 2` |
| `**=` | 幂赋值 | `a **= 2`，等同于 `a = a ** 2` |

海象运算符写成 `:=`。它解决的是：普通赋值不算一个会交出结果的表达式。它的优先级很低，Python 3.8 才有。【来自截图】`num1 = 20` 时，`(num2 := 3 ** 2) > num1` 会先把 `9` 赋给 `num2`，再拿 `9` 和 `20` 比较。笔记里的三行是：

```python
print(d := 10)
print(a := 10 > 5)      # 先算 10 > 5，再把 True 赋给 a
print((a := 10) > 5)    # 先把 10 赋给 a，再拿这个 10 去比较
```

比较运算符也叫关系运算符。【来自截图】`a = 1`、`b = 2` 时，`>`、`<`、`==`、`!=`、`>=`、`<=` 的结果依次是 `False`、`True`、`False`、`True`、`False`、`True`。字符串也可以直接比较，按 Unicode 编码。`"a" > "A"` 为真，因为 `"a"` 的编码比 `"A"` 大。

逻辑运算符：

- `and`：第一个条件为假就直接返回，不再看第二个。笔记里的比喻是：没戴口罩就直接拒绝入场，不用再查健康码。
- `or`：第一个条件为真就直接返回，不再看第二个。
- `not`：真变假，假变真。
- 笔记里还记了：`1 and 2` 得到 `2`，`0 and 3` 得到 `0`。`and` / `or` 交出来的是参与运算的那个值，不一定是 `True` 或 `False`。
- 两个条件可以写成 `a < b and a < c`。

成员运算符：`in` 在指定序列里找到值就返回真，否则返回假。`not in` 相反。笔记里的例子是在列表 `[1, 2, 45]` 里找 `1`。

身份运算符：`is` 是同一个对象就返回真，`is not` 相反。上一篇已经记过 `is` 看的是对象，不是值。

流程控制用来决定指令按哪条路走。笔记里的理解是：`0` 或空值为假，其余为真。`if` 按条件选择执行哪一段，`else` 是条件不成立时走的那一段。

## 关键概念

- `//`、`%`、`**`：整除、余数、乘方。它解决什么问题：除了加减乘除，还要表达「分成几整份」「剩下多少」「几次方」。
- 赋值运算符：把运算和写回合成一步。它解决什么问题：少写一遍左边的名字，例如 `a = a + 2` 写成 `a += 2`。
- `:=`：在表达式里面完成赋值，并把赋进去的值交出来。它解决什么问题：赋值之后立刻拿这个值去做比较或打印。
- 比较运算符：比较两个值的大小或是否相等，结果是 `True` 或 `False`。它解决什么问题：给 `if` 提供条件。
- `and` / `or` / `not`：把几个条件合成一个。它解决什么问题：要同时满足、满足一个即可，或者把条件反过来。
- `in`：判断一个值在不在一组数据里。它解决什么问题：不用自己写循环去找。
- `if` / `else`：按真假选择下一条要执行的语句。它解决什么问题：同一个程序可以走出不同结果，例如成年和未成年提示不同。

## 最小例子

```python
print(7 // 2)     # 整除，得到 3
print(7 % 2)      # 余数，得到 1
print(2 ** 3)     # 2 的 3 次方，得到 8

数量 = 10
数量 += 2
print(数量)

print(d := 10)
print(a := 10 > 5)
print((b := 10) > 5)

print(1 and 2)    # 得到 2
print(0 and 3)    # 得到 0

名单 = [1, 2, 45]
print(1 in 名单)

年龄 = 18
if 年龄 >= 18:
    print("恭喜成年")
else:
    print("还没成年呢！")
```

## 补充

- 【补充】`//` 是向更小的整数取。正数看起来像去掉小数，`7 // 2` 得到 `3`。负数会再往小走一格，`-7 // 2` 得到 `-4`。
- 【补充】`and` 和 `or` 会短路：已经能决定结果时，后面的条件不再计算。交出来的是最后看过的那个值，所以 `1 and 2` 是 `2`，不是 `True`。
- 【补充】字典使用 `in` 时，查的是键。这一篇的例子是列表，字典的写法还没有记。
- 【补充】`if` 条件成立时，只执行缩进里面的语句。同一层的 `else` 和 `if` 对齐。

## 修正

- 【修正】逻辑表里「Java 对比：`&&` / ``」那一格是表格列错位 → Java 写成 `&&` 和 `||`，Python 写成 `and` 和 `or`。作用都是「并且」和「或者」，符号不同。
- 【修正】「`not` 里 0 视为假、非零视为真」→ `0` 确实是假，非零数字是真。截图里同样算假的还有 `None`、`0.0`、空字符串和空容器。`not` 只负责把当前这个真假反过来。
- 【修正】「`in` 找到值返回 `T`，否则返回 `F`」→ 返回的是 `True` 和 `False`，不是字母 `T`、`F`。`is` 也一样。
- 【修正】「Python 指定 `0` 或者 `null` 为 false」→ 拼写是 Python。Python 里表示「没有」的是 `None`，不是 `null`。`0`、`None`、空字符串、空容器都是假，其余常见非空值是真。
- 【修正】`if age >= 18` 后面没有冒号 → 条件后面必须写 `:`，下一行再缩进。写成 `if 年龄 >= 18:`。
