## 今天学到的

用单引号或双引号包起来的内容是字符串。可以用 `\` 转义。三引号用来写多行字符串，笔记里把它对应到 Java 的文本块。【来自截图】同一段 HTML，用普通引号时每一行末尾要写 `\n`；改成三引号后，换行直接写在引号里面。直接写在引号里的值叫字面量。笔记里的理解是：字面量是常量，不能修改；字符串相加是拼接，不是数学加法。

字符串有 intern 机制。笔记里的理解是：不含空格或特殊符号的字符串默认开启 intern，相同字符串只留一份，靠引用计数决定是否销毁，用来共享内存。【来自截图】`s1 = "abc"` 和 `s2 = "abc"` 时，`s1 == s2` 是 `True`，`s1 is s2` 也是 `True`，`id(s1)` 和 `id(s2)` 打印出同一个数。

类型转换分两种。自动转换：整数加浮点数，结果是 `float`；整数 `/` 整数，结果也是浮点数。Python 不允许数字和字符串直接相加，`10 + "hello"` 会报错。笔记里对比了 Java 和 JavaScript：那边常会把数字转成字符串再拼接，例如变成 `"10hello"`。

显式转换要自己调用函数。笔记记下的函数有：`int`、`float`、`complex`、`str`、`repr`、`eval`、`bin`、`oct`、`hex`、`ord`、`chr`、`tuple`。数学里的虚部 `i`，Python 写成 `j`，例如 `1j`。

`float` 还能接受特殊字符串：`float("nan")` 表示不是数字，`float("inf")` 表示正无穷，`float("-inf")` 表示负无穷。

【来自截图】数字要放进文字里，可以先用 `str` 再拼接。`age = 20` 时，`"我的年龄是" + str(age) + "岁"` 会得到带数字的句子。不加 `f` 的 `"我的年龄是{age}岁"` 不会把 `age` 换进去，花括号会原样留下。前面加 `f` 才会替换。

`eval` 会执行字符串表达式并返回值。笔记里把它和数学运算、定时任务、自动化脚本放在一起，并记录它还能执行系统命令，所以有危险。

`ord` 按 Unicode 把字符变成整数，例如 `ord("A")` 是 `65`，`ord("a")` 是 `97`，`ord("中")` 是 `20013`。`chr` 做相反的事。

字节长度：笔记记下英文字母固定 1 个字节；中文在 GBK 里占 2 字节，在 UTF-8 里占 3 字节。`encode` 把字符串变成字节，`decode` 把字节变回字符串，两边必须使用同一种编码。

`input` 从控制台读入内容，返回的是字符串。希望得到别的类型时，要再做转换。【来自截图】年龄写成 `age = int(input("请输入你的年龄"))`，再用 `type(age)` 看类型。身高可以先 `input`，再 `float(身高)`。截图里「是否开心」只做了 `input`，没有套 `bool`，所以存下来的仍是字符串。笔记另记了 `bool` 的几个结果：`bool("abc")` 为 `True`，`bool("")`、`bool(0)`、`bool(None)` 为 `False`，`bool("None")` 为 `True`。

`print` 可以输出多项，多项之间用逗号分开，默认在结尾换行。`end` 用来改结尾字符。`\n` 是换行，`\t` 是制表符。

旧式格式化用 `%`。【来自截图】`"a = %d , b = %f" % (1, 2.56789)` 得到 `a = 1 , b = 2.567890`，`%f` 默认 6 位小数。`%.2f` 得到 `2.57`，`%.1f` 得到 `2.6`。画面最上方还有一行以 `1a2b3c` 开头、后面接一串 `*` 的输出，对应源代码被裁掉了，未辨认。

`format` 用 `{}` 占位。【来自截图】`"{0}"`、`"{1}"`、`"{2}"` 按传入的位置填入。大括号里也可以写名字，例如 `"{i1}".format(i1=整数)`，名字要在 `format` 的括号里用 `名字=值` 传进去。冒号后面写格式规则。【来自截图】`"{:*^20,.2f}".format(31415.9)` 里：`*` 是填充字符，不写则用空格；`^` 居中，`<` 左对齐，`>` 右对齐；`20` 是宽度；`,` 每 3 位分隔；`.2f` 保留两位小数。要显示大括号本身，写成 `{{` 和 `}}`。【来自截图】`"{0} 对应的位置是 {0}".format("hello")` 两处都变成 `hello`；`"{} 对应的位置是 {{0}}".format("hello")` 会留下字面的 `{0}`。

字符串前面加 `f` 就是 f-string，从 Python 3.6 起可以直接把变量嵌进去。【来自截图】`f"int1 = {int1}, float1 = {float1}"` 会把变量的值放进句子。Python 3.8 起，花括号里写成 `{变量名 = }`，打印时会同时看到名字和值。

## 关键概念

- 字符串：引号里的文本。它解决什么问题：保存姓名、提示语这类文字。
- 字面量：源码里直接写出的值，例如 `"你好"`。它解决什么问题：区分「写死在代码里的值」和「跑起来以后才得到的值」。
- intern：让某些相同的字符串共享同一个对象。它解决什么问题：重复出现的字符串少占内存。截图证明的是两个 `"abc"` 字面量共用一个对象。
- 自动转换：运算时 Python 自己决定结果类型。它解决什么问题：整数和浮点数相加时，结果保留小数。
- 显式转换：用 `int`、`float`、`str` 这些函数明确转换。它解决什么问题：`input` 得到的永远是字符串，要拿来计算就必须自己转。
- `encode` / `decode`：字符串和字节之间的转换。它解决什么问题：文件、网络传的是字节，程序里处理的是字符串，两边编码必须一致。
- `print`、`format` 和 f-string：把结果显示出来，并把变量嵌进文字。它解决什么问题：看到程序算出了什么。新代码优先用 f-string。

## 最小例子

```python
问候 = "你好"
多行 = """第一行
第二行"""
拼接 = 问候 + "，世界"

年龄 = 20
print("我的年龄是" + str(年龄) + "岁")
print("我的年龄是{年龄}岁")          # 没有 f，花括号原样留下
print(f"我的年龄是{年龄}岁")

文字 = input("请输入姓名：\n")
数字 = int("10")
身高文字 = "1.70"
身高 = float(身高文字)

原文 = "123"
字节 = 原文.encode(encoding="utf-8")
还原 = 字节.decode(encoding="utf-8")

print("a = %d , b = %.2f" % (1, 2.56789))
print("int1 = {0}".format(10))
print(f"{年龄 = }")
```

## 补充

- 【补充】整数除法写成 `/` 时，结果是浮点数，例如 `3 / 2` 得到 `1.5`。只要整数商，用 `//`，`3 // 2` 得到 `1`。
- 【补充】`int("11", 2)` 可以把二进制字符串转成整数。`base` 只能和字符串一起用，`int(11, 2)` 会报错。
- 【补充】`repr` 返回给读代码的人看的表示。字符串里的换行会显示成 `\n` 这种形式，方便看清内容到底长什么样。
- 【补充】`bool` 里只有空字符串、`0`、`None`、空列表这类值是 `False`。字符串 `"None"`、`"0"`、`"False"` 都不是空的，所以是 `True`。截图里的「是否开心」没有调用 `bool`，输入 `False` 四个字母时，变量里仍是字符串 `"False"`。
- 【补充】`print` 里逗号只负责隔开多项。结尾换行来自 `end`，默认值是 `"\n"`，它不是「第二个入参」这个位置参数。
- 【补充】`.2f` 是在现有二进制小数上格式化。`0.1` 本身常常存不准，所以看起来会和小学的四舍五入不一致。金额继续用 `Decimal`。
- 【补充】现在写新的格式化文字，优先用 f-string。`%` 和 `format` 是笔记里一起学过的旧写法，读到旧代码时要认得。

## 修正

- 【修正】「字面量是常量，无法修改」→ 字符串对象不能改掉里面的某一个字符。变量可以改去指向另一个字符串，例如 `问候 = "你好"` 之后再写 `问候 = "再见"`。字面量指的是源码里直接写出的那个值。
- 【修正】「不含空格或特殊符号就默认 intern，相同字符串只留一份」→ 不是运行中出现的每一个这种字符串都会自动 intern。截图只演示了两个 `"abc"` 字面量共享对象。程序跑起来以后拼接出来的字符串通常各自一份。一定要共享时，用 `sys.intern`。引用计数是解释器回收对象的机制，不等于 intern 的定义。
- 【修正】「英文字母固定 1 个字节，中文在 UTF-8 里占 3 字节」→ 这是 `encode` 之后的字节长度，不是 Python 字符串本身按字节存放。UTF-8 里，英文常见是 1 个字节，常见汉字是 3 个字节，也有汉字或表情是 4 个字节。GBK 里常见汉字是 2 个字节。编码和解码不一致会报错，这句原笔记是对的。
- 【修正】「`eval` 的危险示例写成 `eval("_import_(os).system(...)")`」→ 内置函数名是 `__import__`，两边各两个下划线。笔记里的 `_import_` 并不能按那个示例执行。需要记住的是：`eval` 会把字符串当成代码运行，不要把用户输入交给它。
- 【修正】「`print` 默认自动添加第二个入参的值为 `\n`」→ 默认换行是关键字参数 `end="\n"`，不是固定的第二个位置参数。
- 【修正】「`format` 的大括号中使用变量」→ 那张截图里，`{i1}` 是传给 `format` 的参数名，要写成 `.format(i1=整数)`。把变量名直接写进大括号，是 f-string 的写法，字符串前面要有 `f`。
- 【修正】「使用大括号转译大括号」→ 这里的用词是转义。要输出一个 `{`，就写成 `{{`。
