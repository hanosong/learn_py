## 今天学到的

【来自截图】平时说 Python 是解释型语言，这个说法成立。从更细的步骤看，它也会先做一次很短的编译，短到毫秒级，写代码时感觉不到。`.pyc` 文件对写程序的人不可见。`hello.py` 里的 `print('hello world')` 会经过：语法检查、词法分析、生成抽象语法树（AST）→ 把 `.py` 编译成 `.pyc` → Python 虚拟机加载 `.pyc` → 解释器执行 `.pyc`。

整数有小整数池，用来少占内存。【来自截图】`a = 10`、`b = 10`、`c = 10` 三个名字都指向堆（heap）里同一个 `10`。图上标的范围是 `-5` 到 `256`。

浮点数使用 IEEE 754，Java 和 C 也用这个标准，因为 CPU 用的就是这套规范，这样计算更快。金额不能用 `float`。【来自截图】`0.1 + 0.2` 的结果是 `0.30000000000000004`。需要精确小数时，从 `decimal` 模块导入 `Decimal`，并用字符串创建。图上的例子是 `Decimal('1.0') - Decimal('0.9')`。笔记里自己的例子是 `Decimal("2.123131233")`。【来自截图】浮点数也可以用科学计数法，`1.3e7` 打印出来是 `13000000.0`。

`bool` 用来表示真和假，只有 `True` 和 `False`。【来自截图】Python 3 里 `bool` 是 `int` 的子类，所以 `True` 和 `False` 可以参与数字运算。`True == 1`、`False == 0` 的结果都是 `True`；`True is 1`、`False is 0` 的结果都是 `False`。值相同，并不等于是同一个对象。

`==` 比较两边的值是否相同。`is` 比较内存里是不是同一个对象。【来自截图】`True` 是全局单例：`a = True`、`b = True`、`c = True` 都指向堆里同一个 `True`。

【来自截图】能当成假的值，除了 `False`，还有 `None`、`0`、`0.0`，以及所有空容器：空列表、空元组、空字典、空集合、空字符串。笔记在这张图旁边标了 `[]`、`()`、`{}`。

## 关键概念

- 执行前的几步：先检查语法并生成 `.pyc`，再由虚拟机执行。它解决什么问题：知道报错可能出在「还没跑起来」的语法检查，也可能出在后面的执行。
- 小整数池：`-5` 到 `256` 里的整数经常共用同一个对象。它解决什么问题：这些整数经常出现，共享对象可以少占内存。
- `float`：带小数的数字，遵循 IEEE 754。它解决什么问题：表示小数。`0.1` 这类十进制小数常常不能精确存成二进制，金额不要用它。
- `Decimal`：用十进制规则保存小数。它解决什么问题：金额这类必须精确的数，要用字符串创建，避免先变成不精确的 `float`。
- `bool`：只有真和假两个值，写作 `True` 和 `False`。它解决什么问题：做判断。
- `==` 和 `is`：`==` 看值，`is` 看是不是同一个对象。它解决什么问题：避免把「长得一样」和「就是同一个」当成一回事。

## 最小例子

```python
# 0.1 和 0.2 直接相加，结果不是精确的 0.3
print(0.1 + 0.2)

# 用字符串创建精确小数
from decimal import Decimal

金额 = Decimal("2.123131233")
差额 = Decimal("1.0") - Decimal("0.9")
print(金额)
print(差额)

print(True == 1)   # 值相同，结果是 True
print(True is 1)   # 不是同一个对象，结果是 False
print(True + 1)    # True 按 1 参与加法，结果是 2
```

## 补充

- 【补充】自己写的代码，仍然按从上往下的顺序执行。赋值先算出右边，再把结果记到左边的名字上。编译成 `.pyc` 是解释器在执行前做的事，这一篇先知道有这个步骤即可。
- 【补充】`-5` 到 `256` 是常见 CPython 的小整数池。这是当前解释器的优化，不是所有 Python 实现的语法规定。判断值是否相等，用 `==`。
- 【补充】`1.3e7` 里的 `e` 表示乘以 10 的若干次方，`1.3e7` 就是 `1.3 × 10⁷`。
- 【补充】`[]` 是空列表，`()` 是空元组。`{}` 是空字典；空集合要写成 `set()`，因为 `{}` 已经被字典占用。列表、元组、字典的具体操作这篇还没有记。

## 修正

- 【修正】「C 语言中也没有 `bool` 类型，所以使用 `1` 或 `0`」→ 早期 C 常用 `1` 和 `0`。C99 之后可以用 `_Bool`，并在 `stdbool.h` 里使用 `bool`。Python 的 `True == 1`、`False == 0` 这层对应关系仍然成立。
- 【修正】「`True = 1`，`flase = 0`」→ 正确写法是 `False`。这里说的是值的对应关系：`True == 1`、`False == 0`。`True` 和 `False` 是关键字，不能写成 `True = 1` 这种赋值。截图里的结果是：`==` 得到 `True`，`is` 得到 `False`。
- 【修正】「`T` 和 `F` 可以和数字相加」→ 参与运算的是 `True` 和 `False`，不是字母 `T`、`F`。
- 【修正】「Global Singlet object」→ 拼写是 Singleton，中文叫全局单例：整个解释器里这个对象只有一份。
